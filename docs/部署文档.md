# 部署运行手册：TSH自动刷课（供自动化代理执行）

本文件是给 AI 代理执行用的操作手册，不是给人看的介绍。所有步骤按 S1…S7 顺序执行；每一步都给出**判定条件**与**失败分支**，不得跳过判定直接进入下一步。文档不含任何特定机器的信息，执行时才由代理读取本机实际值填入 `<占位符>`。

---

```yaml
artifact:
  kind: userscript            # Tampermonkey / Violentmonkey / ScriptCat 均可
  file: tsh-auto-brush.user.js
  version_min: 2.3.0          # 语义化比较：>= 此版本才具备本手册 L 节所述行为
  identity_policy: >-
    不固定哈希、不固定字节数。上游每次发布都会变，写死哈希会把手册变成一次性消耗品。
    校验改为三条不随版本变化的准则：S1 的头部不变量、S6 的静态基线、以及与本地留档的差异检测。
    哈希只计算并记入执行日志，用于事后比对与回归定位，不作为通过/阻断的门禁。
  frozen_snapshot:            # 仅为撰写本手册时的参考锚点，任何情况下不得用作校验门禁
    version: 2.3.0
    bytes: 234859
    lines: 4507
    sha256: 6d241a4924bc190d394270f9156fd65727ccb4c31e393cd9ac0d038fb23383e4
  license: GPL-3.0-only
upstream:
  repo: https://github.com/WASD258-jpg/tsh-auto-brush
  raw_urls:                  # 两者均返回 HTTP 200，任取其一
    - https://raw.githubusercontent.com/WASD258-jpg/tsh-auto-brush/master/tsh-auto-brush.user.js
    - https://raw.githubusercontent.com/WASD258-jpg/tsh-auto-brush/main/tsh-auto-brush.user.js
  releases_api: https://api.github.com/repos/WASD258-jpg/tsh-auto-brush/releases/latest
  releases_assets: "需运行时确认"  # 撰写时为空数组（无可下载资产）；执行时仍应查一次，非空则优先用资产
userscript_header:
  match: "*://www.tsinghuaelt.com/*"
  grant: none                # 无 GM_xmlhttpRequest，无跨域特权
  run_at: document-idle
  updateURL: https://github.com/WASD258-jpg/tsh-auto-brush/raw/main/tsh-auto-brush.user.js
runtime_external_hosts:      # 脚本全部外联域名，仅此 5 个
  - www.tsinghuaelt.com        # 站点本体 + 旧站 API
  - zhjyapi.tsinghuaelt.com    # 新版 API（/elt-user）
  - api.deepseek.com           # 可选：主观题 AI，用户自备 key
  - github.com                 # 可选：失效上报
  - api.github.com             # 可选：失效上报
```

## 变量表（执行前由代理解析）

| 占位符 | 含义 | 解析方式 |
|---|---|---|
| `<BROWSER_EXE>` | 装了用户脚本管理器的浏览器可执行文件绝对路径 | 枚举已安装浏览器，逐个检查其扩展目录中是否存在 `dhdgffkkebhmkfjojejmpbldmpobfkfo`（Chrome/Edge 系 Tampermonkey 通用 ID）或 `iikmkjmpaadaobahmlepeloendndfphd`（Edge 版 TM）；命中那个即为目标浏览器 |
| `<PROFILE_DIR>` | 目标浏览器的用户配置目录 | Chrome/Edge：`<USER_DATA>/Default`；先查 `Default`，无命中再查 `Profile 1`、`Profile 2`… |
| `<EXT_SETTINGS_DIR>` | 用户脚本管理器的扩展数据目录 | `<PROFILE_DIR>/../Local Extension Settings/<TM_EXT_ID>`；用于只读核验安装结果，不需要写入 |
| `<SERVE_DIR>` | 存放 `.user.js` 并对外提供静态服务的目录 | 任选一个持久目录（不要放临时目录，装完要留档） |
| `<FILE>` | 实际使用的那份脚本文件绝对路径 | 由 S1.0 决定：目录里已有 `*.user.js` 则指向它（source=local，不联网）；没有才下载到 `<SERVE_DIR>/tsh-auto-brush.user.js`（source=download） |
| `<LOCAL_BYTES>` | `<FILE>` 的真实字节数 | `wc -c <FILE>`；仅用于 S2-B 的服务一致性自检 |
| `<PORT>` | 本地静态服务端口 | 任选空闲端口，默认 8931 |
| `<SCRIPT_URL>` | 交给浏览器安装的 URL | 走 S2-A 时为 upstream.raw_urls 之一；走 S2-B 时为 `http://127.0.0.1:<PORT>/<FILE 的文件名>` |
| `<READER_URL>` | 教材阅读器页面地址 | 从课堂实际页面取得，形如 `https://www.tsinghuaelt.com/course_center/reader/...` 或 `https://www.tsinghuaelt.com/legacy/...` |

**禁止**由代理自行生成或猜测账号、密码、课程 ID、令牌、API Key。缺失时停下并向操作者索取。

## S0 前置硬性条件

必须同时满足，否则后续全部无效：

1. 目标浏览器已安装用户脚本管理器（Tampermonkey ≥ 5.3，或 Violentmonkey）。未安装 → 先装，扩展商店条目：
   - Edge：`https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd`
   - Chrome：`https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo`
2. 操作者在该浏览器中已登录 `https://www.tsinghuaelt.com`（登录入口 `https://www.tsinghuaelt.com/login-new`，被分流的账号会落到 `/legacy/login`）。
3. 浏览器版本 ≥ 138 时，须完成 S3 的「允许用户脚本」授权；该授权缺失的表现与「脚本未安装」完全一致，不可据此判定安装失败。

## S1 选定脚本文件并校验（不考虑浏览器）

> GitHub raw 与 api 在本网络下经常超时或返回空 body，因此**本手册不把联网当作前提**：本地已有文件时全程不联网。

### S1.0 本地优先（第一步永远是这个判断）

```
ACTION: 在 <SERVE_DIR> 下查找 *.user.js
ACTION: ls -la <SERVE_DIR>/*.user.js（Windows：ls -la <SERVE_DIR>）
```

判定：

```
IF 找到 1 个文件
   THEN <FILE> = 该文件绝对路径；source = local
        记录 path / 字节数 / mtime / sha256
        不发起任何网络请求，直接进入 S1.1
IF 找到多个文件
   THEN 取 @version 数值最高、mtime 最新者作为 <FILE>，其余记录但不使用；
        若有同名不同版本的副本，把旧的那个重命名为 *.user.js.bak 以便 S1.4 做差异比对
        source = local，进入 S1.1
IF 一个都没有
   THEN <FILE> = <SERVE_DIR>/tsh-auto-brush.user.js，source = download
        进入 S1.3 下载
```

本地文件已存在时不要再下载覆盖：覆盖会把「已验证可用的那一份」换成「可能下载到半截的那一份」。

### S1.1 记录指纹（不与任何常量比对）

对 `source = download` 的文件在下载完成后执行；`source = local` 的文件同样执行一次：

```
ACTION: sha256sum <FILE>
ACTION: 字节数（stat -c %s <FILE> 或 wc -c <FILE>）
ACTION: 读取前 16 行的 @version
ACTION: 三项写入执行日志
```

**哈希只记录、不作门禁。** 上游每次发布哈希都会变，写死会让本手册在下个版本就失效。判定只依赖下面的不变量与静态基线。

### S1.2 头部不变量（必须全部成立）

读取 `<FILE>` 前 16 行的 userscript 头部，逐条比对：

```
IF @match 严格等于 "*://www.tsinghuaelt.com/*"      ELSE 停止（脚本被授权到本域之外的站点，行为已变）
IF @grant 严格等于 "none"                            ELSE 停止（出现 GM_* 特权即可跨域外发，须重新审查）
IF 不存在 @require 条目                              ELSE 停止（引入未锁定版本的第三方代码）
IF @version 按语义化数值比较 >= 2.3.0                ELSE 停止（低于此版本无跨节推进，且 D3/D7 所述缺陷仍在）
IF 以上全部成立                                      THEN 进入 S1.4
```

`@version` 用数值逐段比较（`2.10.0` > `2.9.0`），不要用字符串比较。

### S1.3 下载（仅在本地没有文件时执行）

按 `upstream.raw_urls` 顺序逐个尝试，任一成功即停：

```
ACTION: curl -sSL --max-time 60 -o <FILE> <raw_url>
ACTION: 校验下载结果：文件存在 且 字节数 > 50000 且 前 3 行包含 "==UserScript=="
```

判定：

```
IF 校验通过                          THEN 进入 S1.1
IF 校验失败（超时 / 0 字节 / HTML 错误页）THEN 换下一个 raw_url
IF 全部 raw_url 均失败                THEN 改用镜像：
     https://cdn.jsdelivr.net/gh/WASD258-jpg/tsh-auto-brush@master/tsh-auto-brush.user.js
     同样校验字节数与前 3 行
IF 镜像亦失败                         THEN 中止 S1，向操作者输出：
     "网络不可达，无法自动获取脚本。
      请手工下载 tsh-auto-brush.user.js 放入 <SERVE_DIR>，然后从 S1.0 重跑，
      本步骤会自动识别本地文件并跳过下载。"
```

不允许把「下载失败」当成通过；也不允许用残缺文件继续（字节数校验就是为此）。

### S1.4 静态基线（S6）与可选差异比对

```
ACTION: 执行 S6 全部检查（纯本地 grep，不联网）
IF 全部符合 THEN 把 <FILE> 交给 S2
ELSE 停止，输出偏离项与上下文行号
```

若 `<SERVE_DIR>` 里存在 `*.user.js.bak`（S1.0 归档的旧版本），额外执行：

```
diff <FILE> <FILE>.bak
```

差异行数写入执行日志，用于事后追溯"从哪一版开始行为变了"；**差异本身不构成阻断**，阻断仍只由 S6 与 S1.2 决定。

## S2 安装脚本（二选一）

### S2 路径选择（先判断，再执行）

```
IF S1.0 判定 source = local   THEN 必须走 S2-B（本地文件不可能通过上游 URL 安装）
IF source = download          THEN S2-A 优先；S2-A 打不开安装页时退到 S2-B
```

### S2-A 直连安装（有外网时优先）

```
ACTION: 用 <BROWSER_EXE> 打开 <SCRIPT_URL>（= 上游 raw URL）
```

判定：页面标题/内容包含脚本名 `TSH自动刷课`，版本行与 S1 记录的实际 `@version` 一致，且存在「安装」按钮 → 由操作者点击一次（用户脚本安装必须由人确认，代理不得用自动化点击绕过）。

若页面打不开或落到 HTML 错误页（GitHub 网络问题），直接改用 S2-B，不要反复重试。

### S2-B 本地文件安装（离线、留档、或 GitHub 不可达时）

`.user.js` 直接以 `file://` 打开时浏览器常拒绝安装，因此必须经 HTTP 提供：

```
ACTION: cd <SERVE_DIR>            # 必须与 <FILE> 所在目录一致
ACTION: 启动 python -m http.server <PORT> --bind 127.0.0.1（后台进程）
ACTION: 读取 <FILE> 的真实字节数 <LOCAL_BYTES>（wc -c）
ACTION: 自检 HTTP 层（URL 用 <FILE> 的实际文件名，不要假定叫 tsh-auto-brush.user.js）
        curl -s -o /dev/null -w "%{http_code} %{size_download}\n" "http://127.0.0.1:<PORT>/<FILE 的文件名>"
```

自检判定（与本地文件比对，不引用任何固定字节数）：

```
IF 状态码 200 且 size_download == <LOCAL_BYTES>
THEN 用 <BROWSER_EXE> 打开该 URL，等待操作者点击「安装」
ELSE 依次检查：端口是否被占用 / <FILE> 是否就在 <SERVE_DIR> 根下（不在子目录）/ 文件名大小写
```

安装完成后必须关闭该 HTTP 服务（结束后台进程）。服务仅绑定 127.0.0.1，但仍不应长期运行。

安装期间服务日志应出现两次取件（`200` 与随后的 `304` 或再次 `200`）；只出现一次说明安装页未真正触发。

### S2-C 管理器内置安装

Tampermonkey 仪表盘 → 实用工具 → Install from URL → 粘贴 `<SCRIPT_URL>`（上游 raw URL 或 `http://127.0.0.1:<PORT>/...` 均可）→ 安装。适用于浏览器不接管 .user.js 直开的情况。

### S2 验收（外部可查，不依赖页面观感）

只读检查 `<EXT_SETTINGS_DIR>` 下的 leveldb 文件（`*.log`、`*.ldb`），用二进制安全的方式检索：

```
grep -a -c "tsh-auto-brush" <EXT_SETTINGS_DIR>/*.log
```

判定：

```
IF 命中数 > 0  THEN 安装记录已落库，进入 S3
ELSE           THEN 视为未安装，回到 S2
```

最终判据以「S4 面板出现」为准；上述检索仅用于在不方便看页面时缩小范围。

## S3 开启用户脚本执行权限（Chromium ≥ 138 必做）

未授权时脚本被静默阻止，页面无任何报错。识别特征：管理器仪表盘顶部出现黄色横幅「请启用「允许用户脚本」扩展设置」。

```
ACTION: 打开 <BROWSER_EXE> 的扩展管理页
        Chrome: chrome://extensions/     Edge: edge://extensions/
ACTION: 定位用户脚本管理器卡片 → 详细信息
ACTION: 打开「允许用户脚本」(Allow User Scripts) 开关
ACTION: 回到 <READER_URL> 强制刷新（F5 / Ctrl+R）
```

判定：

```
IF 浏览器主版本 < 138          THEN 该开关不存在属正常，跳过本步
IF 找不到开关                   THEN 检查该扩展卡片「…」菜单 / 「网站访问权限」区域
IF 开关打开且刷新后仍无面板      THEN 进入 S7 的 D1 分支
```

## S4 站点轨道判定（决定脚本用哪套引擎，代理据此校验行为）

站点自 2026-09 起双轨运行，两套前端共用同一域名，脚本按路径自动分派：

| 地址栏正则 | 前端 | 生效引擎 | API 域 | 鉴权 |
|---|---|---|---|---|
| `/course_center/` | 新版「智慧版」（Vue3 + Vite） | 新版引擎 | `zhjyapi.tsinghuaelt.com/elt-user` | 请求头 `elt-user-token`；令牌在 `localStorage.eltUserToken` |
| `/legacy/` | 旧站（Angular 7，未下线） | 旧站引擎 | `www.tsinghuaelt.com/tsenglish/` | `sign` = MD5(serverTime+clientTime+paramKeys+userId) + `sea-fetch-path` + AES 衍生头 |
| 其他（首页、课程列表） | — | 待命 | — | 进入教材章节后才启用 |

分流原因：登录经统一认证中心 `uc.izhixue.cn`，`type === 3` 的账号被送往 `/legacy/login`，全程不签发新站令牌。因此**账号属性决定前端，不由用户选择**。

代理注意：不得跨轨道套用结论。新版接口 `questionVOList[].answer` 实测恒为空字符串；旧站的「提交假数据 → 读回标准答案 → 再提交」试错法在新版不成立。

## S5 页面内配置与验收

### S5.1 面板存在性（唯一的安装成功判据）

```
ACTION: 打开 <READER_URL>，等待 DOM 就绪（脚本 @run-at document-idle）
CHECK : 文档右下角出现脚本面板，标题栏版本号与 S1 记录的 @version 一致（且 >= 2.3.0）
```

```
IF 面板存在 THEN 继续
ELSE        THEN 转 S7-D1
```

### S5.2 结构自检（每次站点改版后必做）

```
ACTION: 点击面板「结构自检」
READ  : 输出中应包含——路由解析结果、令牌是否存在（不含内容）、DOM 探针命中数、
        题卡推断题型与数量、提交/分页按钮状态、取题接口字段名与长度
```

判定：

```
IF 路由识别与 S4 表格一致 AND 令牌存在 AND 题卡探针命中数 > 0 THEN 通过
IF 探针命中数为 0 且连续 10 轮如此 THEN 判定脚本对当前站点失效，进入 D5
```

自检输出不含账号、姓名、学校、课程名、题目内容、令牌值，可安全对外传输。

### S5.3 配置项（只暴露必要开关，其余保持默认）

面板「设置」中的可配置项及其默认/推荐值：

| 配置 | 默认 | 代理应设的值 | 说明 |
|---|---|---|---|
| 启用 AI 补答 | 关 | **仅当需要处理主观题时开** | 客观题不需要 AI |
| API Base URL | 空 | `https://api.deepseek.com/anthropic` | 含 `anthropic` 走 Anthropic Messages（`/v1/messages` + `x-api-key`）；否则走 OpenAI `chat/completions`；末尾带不带 `/v1` 均可识别 |
| 模型名 | 空 | `deepseek-flash` 或 `deepseek-v4-pro` | 推理模型会先输出 thinking |
| API Key | 空 | 由操作者提供 | **不得由代理生成或索取明文** |
| 失效上报 | 关 | **保持关** | 开启需操作者自备 GitHub fine-grained token（Issues: Read and write），并先签署知情同意 |
| Course（课程） | 自动识别 | 仅在课程列表页操作时需要手动指定 | 列表页 URL 与 DOM 中均无 courseId（Vue 编程式路由），脚本取不到 |

已知必须保持的取值（改动会导致功能异常，代理不得"优化"）：

- AI 单次额度 **16384**：推理模型的思维链会吃掉较小额度，导致正文为空、`stop_reason: max_tokens`。
- **不得禁用思维链**：禁用后更快但答案质量明显下降。
- 请求超时 **90 秒**：复杂题单次可超 15 秒。
- 听力/音频题必须把 `attachmentList[].script` 原文与 `instruction` 一并放入 prompt，否则模型只能猜测。

跨域可行性（无需代理干预，仅作判断依据）：目标 AI 端点对站点来源反射 `access-control-allow-origin`，故 `@grant none` 下 `fetch` 直连可用，不需要本地反代。

### S5.4 存储位置与生命周期

AI Key、上报 token、各开关存于浏览器 `localStorage`（明文）。清站点数据、换浏览器配置、换机器均会丢失，需重填。代理不得把该值写入任何日志、文件或对话。

### S5.5 功能验收（按序执行，任一步失败即停）

| 序 | 动作 | 通过判据 |
|---|---|---|
| 1 | 点「做一轮」 | 状态输出包含 取题 → 作答 → 提交 → 推进 各阶段，无异常中断 |
| 2 | 点「查成绩」 | 输出课程名、成绩/进度/时长，以及各单元明细（成绩、进度、时长） |
| 3 | 点「开始刷课」，观察 ≥ 2 节 | 地址栏出现逐节跳转；已处理 `contentId` 不重复；连续 3 次无推进即自行停止 |
| 4 | 点「停止」后刷新页面 | 不再自行继续（状态已清除） |

## S6 安全基线（变更上游版本时须重新核对）

安装前对 `.user.js` 执行的静态检查。**任一项偏离，都视为上游行为已变，须重新审查后才可继续；这些判据不随版本失效。**

| 检查项 | 命令 | 通过判据（与具体版本无关） |
|---|---|---|
| 外联域名集合 | `grep -ohE 'https?://[a-zA-Z0-9._-]+' <file> \| sed 's\|https\?://\|\|' \| sort -u` | 集合等于 runtime_external_hosts 清单（撰写时 5 个）；**出现清单之外的域名即偏离，尤其不得出现作者自建域** |
| 远程代码执行 | `grep -c -E 'eval\(\|new Function\|@require' <file>` | `0` |
| 跨域特权 | `grep -c 'GM_xmlhttpRequest' <file>` | `0` |
| Cookie 外发 | `grep -c -E 'document\.cookie\|sendBeacon' <file>` | `0` |
| 令牌外发 | `grep -n 'eltUserToken' <file>` | 仅出现在对 `zhjyapi.tsinghuaelt.com` 的请求构造中 |
| 更新通道 | 读 `@updateURL` | 只把 `.user.js` 交给管理器走常规更新弹窗；不含 eval/动态 import |

判定：

```
IF 全部符合 THEN 可安装
ELSE          THEN 阻断安装，输出偏离项与上下文行号，交人工决策
```

## L 硬性限制（不可通过配置或重试绕过）

**L1 语音题跳过 ≠ 完成。** 口语、跟读、角色扮演、词汇题走驰声 chivox 实时语音评测（WebSocket + 麦克风采集 + 服务端打分），必须真人录音。脚本会识别并跳过，同时调用 `apiMarkContentDone` 让流程能继续，但这类题**拿不到分**；跳过不等于完成，可能造成该单元进度停滞。自动刷课时遇到语音题不停，跳过并继续下一节。代理不得伪造音频。

**L2 作业与考试模块不做。** 该模块有全屏监控、切屏自动提交、人脸抓拍等强反作弊，脚本不触碰。代理不得尝试绕过。

**L3 分数取值由课程配置决定，不可假定。**

```
learnMode = 1 → 自由模式：成绩记「末次」答题结果 → 反复提交有代价，最后一次即最终成绩
learnMode = 2 → 闯关模式：成绩记「最高」答题结果 → 反复提交无害
相关字段：learnMode / freeShowAnswer / errorNumShow / caculateToGrade / learnTimeLimit
读不到课程设置时的策略：按最保守处理，不做试错
```

**L4 答案来源与阈值。** 客观题的标准答案只在答错累计到 `errorNumShow` 次后由服务端下发（`questionAnswerItemVOList[].answer`）；答对则回显自己提交的答案。`questionVOList[].answer` 恒为空。主观题（`obSub: 'sub'`）`answerStatus` 恒为 `-1`，服务端永不下发答案，只能 AI 作答，且不自动判分，最终分数取决于教师批改。

**L5 成绩与学习时长是两条独立通道。** 看板返回 `score` / `progress` / `duration`，其中 `duration` 只参与排名，不计入 `score`。站点自身每 10 秒上报一次时长，空闲满 10 分钟会跳过上报，「时长保活」只用于防止该熔断，不用于"刷时长"。

**L6 行为会被记录。** 全站开启阿里云 RUM 会话回放（`replay: true`，100% 采样），操作节奏被记录。教材阅读器内部经全量产物扫描未发现行为监控（`cheat`/`face`/`monitor`/`visibilitychange`/`blur`/`fullscreenchange` 均 0 命中），站内亦无 `sendBeacon` 或自建埋点。代理不得为规避记录而改造页面或拦截上报。

**L7 自动化边界。** 用户脚本安装确认、账号登录、API Key 输入必须由人完成，代理不得代为执行或索取明文凭据。

## 上游已知缺陷（执行时不要试图"修"）

站点登录链路 `uc.izhixue.cn/js/login.js` 对 `type === 3` 分流的账号会把密码明文拼进 URL：`https://www.tsinghuaelt.com/legacy/login?appId=user_center&sign=<账号>##<密码明文>`，进入浏览器历史并可被分析类 SDK 采集。这属于平台实现缺陷，不是脚本行为；代理不应改写该跳转，也不应记录该 URL。
